# Todo App

This context describes the language for a personal todo application used by one person to track work they want to complete.

## Language

**Todo**:
A single piece of work the person wants to track until it is complete.
_Avoid_: Task, item

**Title**:
The short text that names what a Todo is about.
_Avoid_: Name, description

**Open**:
The state of a Todo that still needs attention.
_Avoid_: Active, pending

**Completed**:
The state of a Todo that the person considers finished.
_Avoid_: Done, closed
